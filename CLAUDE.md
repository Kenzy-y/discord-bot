# CLAUDE.md

## Проект

Discord-бот: заходит в голосовой канал и проигрывает звуки из `sounds/` в случайном порядке со случайными паузами. Звуки добавляют владелец и коллабораторы обычными коммитами. Бот работает на домашнем ПК владельца; Discord доступен только через системный VPN (голос идёт по UDP) — учитывать при диагностике сетевых ошибок.

`/start` играет бесконечно (звук → случайная пауза → звук…) до `/stop`, `/leave` или отключения; `config.toml` и `sounds/` перечитываются перед каждым звуком.

Задачи приходят итерациями в `tasks/prompt-NN-*.md`, отчёты сохраняются в `tasks/report-NN.md`.

## Стек

- Python 3.11+ (нужен `tomllib`), venv в `.venv/` (сейчас 3.12).
- `discord.py[voice] >= 2.7.1` — обязательно. С марта 2026 голос Discord требует DAVE (E2EE), поддержка через пакет `davey` (ставится с extra `voice`); без него — закрытие с кодом 4017. API голоса сверять с установленной версией в `.venv`, а не с памятью.
- FFmpeg в PATH; воспроизведение через `FFmpegOpusAudio.from_probe` (Opus без перекодирования).
- `python-dotenv` для `.env`, `pytest` для тестов (`pytest` из корня).
- Только непривилегированные intents (`guilds`, `voice_states`).

## Структура

```
bot/
  __main__.py   точка входа (python -m bot): логирование, .env, запуск
  client.py     SoundBot: intents, синхронизация команд, on_voice_state_update
  commands.py   слэш-команды /connect /start /stop /leave
  voice.py      выбор канала и подключение/перемещение
  session.py    SessionManager: бесконечная фоновая сессия на сервер; плеер и sleep подменяются в тестах
  config.py     загрузка и валидация config.toml (секция = dataclass), ConfigReloader
  sounds.py     список звуков в sounds/
  checks.py     проверки окружения (ffmpeg, davey, sounds/)
  paths.py      пути относительно корня репозитория
tests/          pytest-тесты без Discord (зависимости — requirements-dev.txt)
sounds/         звуковые файлы
config.toml     настройки случайности
tasks/          задачи от владельца
```

## Правила работы

- Делать только то, что описано в задаче. Идеи сверх — в раздел «Вопросы и предложения» отчёта, не реализовывать.
- В конце каждой задачи — отчёт по шаблону из текущей задачи (шаблон может меняться), сохранённый в `tasks/report-NN.md`.
- Ответы бота и комментарии в `config.toml` — на русском.
- Не коммитить секреты (`.env`, токены); токен не должен попадать в логи.
- Коммитить по завершении задачи, push не делать без явной просьбы.
