# Discord-бот случайных звуков

Бот заходит в голосовой канал и проигрывает звуки из папки `sounds/` в случайном порядке со случайными паузами.

## 1. Создание бота в Discord

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**, задайте имя.
2. Раздел **Bot** → **Reset Token** → скопируйте токен. Это пароль бота: никому не показывайте и не коммитьте.
   Привилегированные intents (Presence, Server Members, Message Content) включать **не нужно**.
3. Раздел **OAuth2** → **URL Generator**:
   - Scopes: `bot`, `applications.commands`;
   - Bot Permissions: **View Channels**, **Connect**, **Speak**.
4. Откройте сгенерированную ссылку и добавьте бота на свой сервер.
5. ID сервера (для `GUILD_ID`): в Discord включите *Настройки → Расширенные → Режим разработчика*, затем ПКМ по серверу → **Копировать ID сервера**.

## 2. Установка

### Python

Нужен Python **3.11 или новее** (проверено на 3.12). Windows: установщик с [python.org](https://www.python.org/downloads/) (отметьте «Add python.exe to PATH»). Linux: пакет `python3` и `python3-venv` из репозитория дистрибутива.

### FFmpeg

FFmpeg должен быть доступен в `PATH` (вместе с ним обычно ставится `ffprobe`, он тоже используется).

- **Windows:** `winget install Gyan.FFmpeg`, затем перезапустите терминал. Или скачайте сборку с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), распакуйте и добавьте папку `bin` в `PATH`.
- **Linux:** `sudo apt install ffmpeg` (Debian/Ubuntu), `sudo dnf install ffmpeg` (Fedora), `sudo pacman -S ffmpeg` (Arch).

Проверка: `ffmpeg -version`.

### Зависимости

Windows (PowerShell):

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Проверка: `python -m discord --version` — в выводе должна быть строка `davey`. Без пакета `davey` Discord не пустит бота в голосовой канал (ошибка 4017: с марта 2026 голос требует сквозного шифрования DAVE).

### Настройка `.env`

Скопируйте `.env.example` в `.env` и заполните:

- `DISCORD_TOKEN` — токен бота;
- `GUILD_ID` — необязательно. Если указан, команды появятся на этом сервере сразу. Если пусто, команды регистрируются глобально, это может занять до часа.

## 3. Запуск

```bash
python -m bot
```

(в активированном виртуальном окружении, из корня репозитория). Остановка: `Ctrl+C`.

При запуске бот предупреждает в логе, если не найден FFmpeg, не установлен `davey` или нет звуков.

## 4. Команды

| Команда | Что делает |
|---|---|
| `/connect` | Заходит в ваш голосовой канал. Если вы не в голосе — в случайный канал, где у бота есть права Connect и Speak, есть места и который не является AFK-каналом. Если бот уже в другом канале — переходит. |
| `/start` | Начинает сессию: проигрывает случайное количество случайных звуков со случайными паузами. Если бот не в голосе — сначала подключается как `/connect`. |
| `/stop` | Останавливает сессию и текущий звук. Бот остаётся в канале. |
| `/leave` | Останавливает сессию и выходит из голосового канала. |

Ошибки видны только тому, кто вызвал команду.

## 5. Как добавлять звуки

Положите файлы в папку `sounds/` и закоммитьте. Поддерживаемые форматы: `.ogg`, `.opus`, `.mp3`, `.wav`. Подпапки не просматриваются. Список файлов перечитывается при каждом `/start`, так что после `git pull` перезапускать бота не нужно.

Рекомендуемый формат — **Ogg Opus**: Discord передаёт звук в Opus, поэтому такие файлы идут без перекодирования, а весят мало. Конвертация:

```bash
ffmpeg -i input.mp3 -c:a libopus -b:a 96k -ar 48000 output.ogg
```

## 6. Настройки `config.toml`

Перечитываются при каждом `/start`.

| Параметр | Смысл |
|---|---|
| `playback.pause_min`, `playback.pause_max` | Пауза между звуками в секундах. Каждый раз выбирается случайное дробное число из диапазона. |
| `playback.plays_min`, `playback.plays_max` | Сколько звуков проиграть за один `/start`. Выбирается случайное целое число из диапазона. |

Ограничения: все значения неотрицательные, `plays_min >= 1`, `min <= max`, `plays_*` — целые. При ошибке бот пишет её в лог и в ответ на `/start`, сессия не запускается.

## 7. VPN

Discord заблокирован в России, поэтому боту нужен VPN, который работает **на всю систему** (не только в браузере) и **пропускает UDP**: текстовая часть Discord работает по HTTPS/WebSocket, а голос — по UDP. Типичные симптомы проблем с VPN:

- бот не запускается с ошибкой «Нет связи с Discord» — VPN выключен;
- бот онлайн и отвечает на команды, но не может подключиться к голосу (таймаут) — VPN не пропускает UDP.
